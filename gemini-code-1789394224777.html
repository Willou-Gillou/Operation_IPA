Note : L'archive doit déjà contenir la signature finale (Distribution/Ad-Hoc).
Que fait cette application ?
  • Extraction : Le script localise votre fichier .app caché dans l'arborescence (Products/Applications/).
  • Formatage : Il génère un dossier virtuel nommé Payload, une structure requise par iOS.
  • Empaquetage : Votre application est placée dans ce dossier, puis l'ensemble est compressé au format ZIP.
  • Génération : L'extension de l'archive est renommée en .ipa et le téléchargement démarre.
🔒 100% Local : Tout le traitement s'effectue dans votre navigateur. Aucun fichier n'est envoyé sur un serveur distant.
